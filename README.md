## 🔧 What I Do

I work with **Android system engineering**, focusing on platform customization, system porting and low-level modifications.

| | Area | Focus |
|---|---|---|
| 📱 | **Custom ROMs & Porting** | System adaptation, firmware integration and cross-device porting |
| ⚙️ | **Android Framework** | Framework modifications, system services, overlays and platform behavior |
| 🔌 | **HAL & Vendor** | Hardware abstraction, vendor integration and device compatibility |
| 🛠️ | **KernelSU Development** | Systemless modules, mount systems and Android system modifications |
| 🛡️ | **System Internals** | SELinux, permissions, system properties and security policies |
| 🐛 | **Debugging & Optimization** | ADB, logcat, dumpsys and troubleshooting |
| 🤖 | **Automation** | Python and shell scripting for Android development workflows |
